# Security policy

Security fixes target the latest published version. Download installers only from
this repository's Releases. Current binaries are unsigned; verify release checksums.

For a vulnerability, use GitHub's **Security → Report a vulnerability** when available.
Do not include exploit details, credentials or personal data in a public issue.
If private reporting is unavailable, open a minimal issue asking for a private
contact without disclosing the vulnerability. No response-time guarantee is offered.

For ordinary endpoint changes, missing notifications and UI bugs, use Issues.
The app does not request Fab credentials. Unexpected requests for credentials,
unrestricted download redirects or execution of source content should be investigated.
