# Fab Watch 1.3.1 — first public GitHub release

Free Windows x64 monitoring for Fab seller reviews, linked discussion comments
and official Unreal Engine Release/Hotfix/Preview announcements.

## Download

Download **FabWatchSetup-1.3.1-x64.exe** below. Python is not required. The installer
is unsigned. Compare its SHA-256 with **SHA256SUMS.txt** from this release.
Source archives are for developers, not required for installation.

## New in this release

- Public MIT-licensed source, English user/developer guides and supplied screenshots.
- Updates dialog: check GitHub, download and verify a newer installer, then confirm
  installation. Daily availability checks run while the main/tray app is running.
- Build/test automation, contribution templates and project metadata for discovery.
- Packaged project/runtime license notices.

Includes the existing persistent popout/Windows reminders, per-event notification
settings, manual read acknowledgement, durable snooze, owner-reply suppression,
automatic discovery of new products and independent Engine monitoring.

## Update and privacy

Existing users: run setup and keep your profile. Settings, history, read confirmations
and snoozes are preserved. Fresh installation has no seller configured. No personal
profiles, databases or diagnostic logs are included in the installer.

## Validation and limits

Windows regression suite and installer payload audit run in CI before publication.
The application has also been tested on the maintainer's existing Windows environment;
a clean-Windows manual installation test was not performed. Automated reminder
tests use controlled clocks, not a real reboot or a ten-minute wall-clock wait.

Public source formats may change. Windows must be running and the user signed in.
Initial source scans are silent history. Engine detection uses versioned topic
titles; edits only inside an existing topic may not create a release event.
This is an independent community app, not an official Epic Games/Fab product.
