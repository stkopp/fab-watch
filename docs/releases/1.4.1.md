Fab Watch shows connection failures in the check status and tries again on the
next scheduled check. A lost connection no longer opens a source error reminder
or adds to the unread count. Existing activity and checkpoints remain available.

To send source format failures to the public issue tracker, open **Settings →
GitHub issue reports** and select an authenticated GitHub CLI. Reports contain
the app version, check type, failure category, HTTP status and response structure.
The option is off by default.

if you already use Fab Watch.
