Fab Watch now keeps popouts in order. A reminder stays visible until you close
it, snooze it or mark it read. To see due items together, choose **Settings →
Notifications → Multiple popouts → Group in one window**. Each item has its own
source and actions. Written review cards show the rating as a number and stars.

- **Unread** opens the unread view. A dot on the tray icon and counts on the tabs
  show when there is something to read.
- **Settings** holds seller, schedule and notification preferences. **Tools**
  holds tests, check details and app updates.
- The forum collector now uses a shared event and checkpoint write path that
  future sources can reuse.

Download **FabWatchSetup-1.4.0-x64.exe** from Assets. The installer is unsigned.
Choose to keep your profile if you already use Fab Watch.

Fab Watch application code was generated with AI and hasn't been reviewed by a
person. The Windows tests and package checks run in GitHub Actions.
